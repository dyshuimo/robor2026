Offline Java robot dependencies for roboRIO image 2026_v1.2

This Maven repository contains unmodified upstream artifacts for this project's
build, tests, and release deployment. build.gradle and settings.gradle prefer it
over external repositories. The normal build/check tasks verify that every build,
Java, test, release-native, and roboRIO JRE dependency resolves from this bundle.
verifyOfflineRoboRio also checks that GradleRIO supports image 2026_v1.2.

Versions:
  GradleRIO / WPILib / WPILib New Commands: 2026.2.1
  REVLib Java and all three native drivers: 2026.0.5
  ReduxLib Java and ReduxLib-fifo native driver: 2026.1.2
  EJML: 0.44.0; Jackson: 2.19.2; Quickbuf: 1.4
  Gradle wrapper: 8.11; Java source, API, and bytecode target: 17

Some upstream dependencies intentionally retain older years in their names:
  OpenCV 4.10.0-3 uses the frc2025 Maven group.
  DeployUtils remains 2025.2.0.
  The roboRIO Java 17 runtime is roborio-2024:17.0.9u7-3.
These are the versions selected by GradleRIO 2026.2.1, not stale robot libraries.

Release native libraries are bundled for roboRIO (linuxathena), macOS
(osxuniversal), and Windows (windowsx86-64). Redux additionally includes debug
drivers and Linux desktop drivers for all platforms in its 2026 vendordep.
Release GUI/Driver Station simulation libraries are included for macOS and
Windows because WPILib also loads these dependencies when running unit tests.
Native debug variants resolve from the normal repositories and require downloads
before offline use. Full offline build/test support covers macOS and Windows;
Linux desktop build/test support requires extending the native artifact bundle.
wpi.java.debugJni = false selects release natives for builds and tests.
The vendor C++ APIs are not bundled because this is a Java project.

Artifacts were downloaded from these repositories or copied unchanged from
Gradle's cache. Repository URLs followed by the relative paths in this directory
identify the original artifacts. SHA256SUMS covers every bundled file except
itself. Archives retain their upstream licenses and third-party notices.

ReduxLib Java is covered by Mozilla Public License 2.0 (LICENSE.txt); its matching
sources JAR is included. ReduxLib-fifo is covered by LGPL 3.0 (LICENSE-driver.txt),
also included inside the native archives. Its source is in the upstream
canandrepo-public repository's reduxfifo directory.

When changing versions, update Gradle/vendordep versions, bundled artifacts,
repository filters, and checksums together. Validate using Java 17:
  ./gradlew clean build --offline
  ./gradlew verifyOfflineDependencies --offline
  cd vendordeps/maven && shasum -a 256 -c SHA256SUMS
The deployment computer still needs its WPILib 2026 / Java 17 / Gradle 8.11
toolchain installed; the Gradle distribution itself is not bundled here.

Hardware checks are separate from build compatibility: confirm the roboRIO image,
use 2026 SPARK firmware with REVLib 2026, and configure the robot's measured
dimensions, gear ratios, device IDs, and encoder directions before driving.
